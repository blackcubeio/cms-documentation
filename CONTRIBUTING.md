# Contributing

[Version française ci-dessous](#contribuer)

Everyone is welcome to contribute!

## Development Branch

- Base branch: `devel`
- Target all PRs to `devel`

## Code Requirements

- **Language**: All code, comments, and documentation must be in English
- **Style**: Follow the existing code style
- **Testing**: Test your changes before submitting
- **Documentation**: Update docs if needed

## Pull Requests

- Fork, branch, commit, push, open PR
- Write clear commit messages
- Describe your changes in the PR

## Issues

- Check existing issues before creating new ones
- Provide clear description and reproduction steps for bugs

## License

Contributions are licensed under BSD-3-Clause.

# Contribuer

Tout le monde est bienvenu pour contribuer !

## Branche de développement

- Branche de base : `devel`
- Toutes les PR doivent cibler `devel`

## Exigences du code

- **Langue** : Tout le code, commentaires et documentation doivent être en anglais
- **Style** : Suivre le style de code existant
- **Tests** : Tester vos modifications avant de soumettre
- **Documentation** : Mettre à jour la doc si nécessaire

## Pull Requests

- Fork, branch, commit, push, ouvrir une PR
- Messages de commit clairs
- Décrire vos modifications dans la PR

## Issues

- Vérifier les issues existantes avant d'en créer
- Fournir une description claire et les étapes de reproduction pour les bugs
