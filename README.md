Blackcube CMS Documentation
===========================

Welcome to the documentation for Blackcube CMS, the CMS built on Yii2. 

This guide will help you understand how to use Blackcube CMS and create websites.

This guide exists in two versions: English and French.
You can access it online at
- [English version](https://cms.blackcube.io/en)
- [Version française](https://cms.blackcube.io/fr)
