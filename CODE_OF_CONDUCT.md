# Code of Conduct

[Version française ci-dessous](#code-de-conduite)

## Our Standards

We are committed to providing a welcoming and inclusive environment. We expect all participants to:

- Be respectful and professional
- Accept constructive criticism gracefully
- Focus on what is best for the community
- Show empathy towards others

## Unacceptable Behavior

- Harassment, discrimination, or offensive comments
- Trolling, insulting, or derogatory remarks
- Personal or political attacks
- Publishing others' private information
- Any conduct that could reasonably be considered inappropriate

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers. All complaints will be reviewed and investigated promptly and fairly.

Project maintainers have the right to remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.

## Scope

This Code of Conduct applies within all project spaces and when representing the project in public spaces.

# Code de conduite

## Nos standards

Nous nous engageons à fournir un environnement accueillant et inclusif. Nous attendons de tous les participants qu'ils :

- Soient respectueux et professionnels
- Acceptent les critiques constructives avec grâce
- Se concentrent sur ce qui est le mieux pour la communauté
- Fassent preuve d'empathie envers les autres

## Comportements inacceptables

- Harcèlement, discrimination ou commentaires offensants
- Trolling, remarques insultantes ou dégradantes
- Attaques personnelles ou politiques
- Publication d'informations privées d'autrui
- Tout comportement qui pourrait raisonnablement être considéré comme inapproprié

## Application

Les cas de comportement inacceptable peuvent être signalés aux mainteneurs du projet. Toutes les plaintes seront examinées et étudiées de manière rapide et équitable.

Les mainteneurs du projet ont le droit de supprimer, modifier ou rejeter les commentaires, commits, code, issues et autres contributions qui ne respectent pas ce Code de conduite.

## Portée

Ce Code de conduite s'applique dans tous les espaces du projet et lorsque quelqu'un représente le projet dans des espaces publics.
